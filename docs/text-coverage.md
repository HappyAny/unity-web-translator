# 文本覆盖检查

本次检查沿四份匹配构建的原生入口、过滤条件、页面队列、扩展后台和写回路径进行。匹配依据为完整 WASM SHA-256。二进制中存在某个接口，和实际画面调用该接口，是两种不同证据；以下不将接口清单当作全画面覆盖证明。

| 文字路径 | 当前范围 | 检查依据 |
| --- | --- | --- |
| TextMeshPro 字符串、格式化、字符数组和 StringBuilder | 三份 TMP 构建的赋值、二维 / 世界空间生命周期、处理数组和绘制入口 | 符号映射、真实 WASM 的 ABI / 重写 / 编译、逐份组件回归测试 |
| 旧版 UnityEngine.UI.Text | 四份构建的赋值、生命周期和 mesh 填充入口 | 原生函数映射和参数、真实 WASM 编译、直接字段写入与异步写回测试 |
| 已接入的完整对白、姓名和逐字窗口 | 已核对的剧情适配器 | 完整句子、推进、闪回保护、暂停和过期结果测试 |
| 显式 JSON 字段 | 用户配置的 URL 和字段规则 | 字符串 token 替换与控制数据保持测试 |
| TextMesh、IMGUI、UI Toolkit | 尚未完整接入 | 存在相关二进制方法；实际使用情况需要分别核对 |
| 网页 DOM / HTML 文字 | 未自动接入 | 现有运行时无 DOM 文字捕获器 |

本次修复了纯汉字原生菜单在没有剧情上下文时被过滤、显示文本的 `|` 片段被整体保留、长段落沿用免费服务的小块限制，以及后台排队被页面等待时间误判成超时的问题。增加旧版 Text 绘制入口和缺少的 TMP 处理入口；译文来源关联防止重新启用组件时翻译自己的输出，超长新文本会解除旧绑定，避免旧译文覆盖新文本。

v0.2.17 对三份 TMP 适配分别复核了菜单、组件复用、绘制更新、暂停、过期结果和托管根释放，并在真实 WASM 上检查新增方法的符号、ABI、导出和编译。下表只使用构建指纹标识适配范围。

| 构建指纹前缀 | 本轮补充 | 字体范围 |
| --- | --- | --- |
| `62bd9e5b` | 世界空间 TMP 启用 / 停用 / 销毁；二维与世界空间绘制检查；旧版 Text 全部捕获入口 | TMP 保留已有的中文备用字体；新增旧版 Text 路径保留原字体，未接入独立中文备用字体 |
| `bd48af83` | 二维与世界空间绘制检查；单独验证既有 TMP / 旧版 Text 生命周期与复用 | 保留已有的 TMP / 旧版 Text 中文备用字体 |
| `adc902bc` | 二维与世界空间绘制检查；原生 novel 当前指令与点击边界；自定义 mesh 绘制入口；当前页限量预读 | 中文优先使用内置 CJK 字体，赋值后刷新自定义字形排版；暂停恢复原字体 |

绘制检查复用现有的捕获与整句保护逻辑：普通 UI 读取当前完整字符串，已翻译的对白在原始绘制前保护译文，不重放逐字动画。原生改写计划最多允许 32 个已核对入口；指纹不匹配时仍保持原始模块。`62bd9e5b` 的旧版 Text 能否完整显示目标语言取决于原字体，不能仅凭字符串写回宣称字形覆盖。

v0.2.18 为 `adc902bc` 区分原生整页数据与当前点击段落。提交当前完整指令并保留先前已显示的段落，译文的可见字数由原生解析器与当前进度决定。自动测试涵盖后续文本隐藏、限量预读、不重复执行窗口回调、同指令重置、配置变化、暂停和句子根释放；原始 WASM 的新增入口、辅助函数与编译已核对。中文原字体的覆盖声明可能与实际字形渲染不一致，因此这一构建的中文输出优先使用内置字体，并在自定义渲染器排版前应用。具体缺字画面仍需新版本客户端复核。

仍保留每项 2000 个 UTF-16 码元、最多 256 个原生绑定、512 个等待请求等有界限制。纯数值和未识别为源语言的内容不自动提交；单独的英文 UI 标签通常仍需词表或进一步接入。权限、翻译开关、接口错误、服务预算和超时也可能保留原文。原生 `TextMesh` 与世界空间 TextMeshPro 是不同路径，后者已接入，前者不能据此宣称支持。

运行诊断只统计已经接入的入口：`nativeCapture.observed` 为观察次数，`nativeBindings` 为活动绑定数，`skipped` 为已知跳过原因。重复绘制可能重复观察同一文字，这些数字不能计算全游戏覆盖率。译文写回后还需要检查字体、排版与画面实际显示。

验证包括先复现失败再通过的原生 UI / 分隔符 / 等待计时测试、真实扩展后台与桥接队列、完整回归，以及四份原始 WASM 的指纹、新增入口符号、签名和编译校验。新版本的 LOG 和更多界面仍需要实际客户端复核，不能将这些检查替代实机验证。
