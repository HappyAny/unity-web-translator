# Architecture

The extension registers isolated and MAIN-world scripts at `document_start` only for user-enabled origins. A top-page origin/path binding chooses the running profile for all authorized frames. Creating or editing a profile alone does not bind a page.

`native-resources.js` validates explicit URL/field rules and edits selected JSON string spans. `native-xhr.js` delays only matching asynchronous XHR completion events. `runtime.js` wraps fetch, owns the cooperative native text API, restores live bridge bindings on pause, and rejects stale results. Matched resource work is bounded and falls back to original text.

`native-wasm.js` instruments explicitly verified WebAssembly modules before instantiation. It matches their full SHA-256, retains copies of original function bodies and dispatches selected functions through typed table entries. It does not rewrite asset bundle responses or alter their CRC checks. Failed setup re-instantiates the original module. `native-labels.js` supplies the verified layout and hooks: managed UTF-16 strings, native TextMeshPro setters, component enable/disable/destroy, and dialogue parsing. Native GC handles keep live labels and original strings valid until a binding is released. Version mismatches are never handled by guessing offsets.

Typewriter balloons bind their complete sentence at initialization. Per-frame prefixes bypass UI translation. Changed outputs use the native full-letter display function after initialization; unchanged outputs do not restart rendering. The initial source retains its native animation. New sentences release the old binding; late translations cannot restart or complete a newer sentence. `native-font.mjs` serves bounded chunks of the packaged OFL font only to authorized, bound pages. `native-font.js` writes it to the engine's in-memory filesystem after native initialization and creates a native dynamic font asset. No host file, game resource bundle or remote font request is involved. The fingerprint-gated adapter appends that asset to existing native fallback lists while keeping their previous entries and original materials. It also observes per-character labels without sending individual translation requests. Components without a usable fallback list use font substitution with their original text color. Labels, fonts and arrays have bounded GC roots; pause restores the original fallback lists and fonts, and native component cleanup releases its roots.

Per-character dialogue binds the complete native window sentence. A changed translation refresh runs the original clear, parse and render path, requests immediate letter visibility and suppresses that refresh's duplicate native log entry. Unchanged output leaves rendering untouched. The renderer's visibility flag does not change native timing, interrupt processing or command completion. The original sentence still records once. Window clear, disposal and script changes release bindings; pause restores the original sentence, and late results cannot update a newer sentence.

Revealable text uses a separate verified hook plan. Whole renderer strings bind as dialogue, with author-name context. Translation refresh calls only the original renderer setter, forces the native mesh to refresh and restores normalized reveal progress. The application's source string, command execution, audio and backlog are not replayed. Native font metadata slots are selected per build fingerprint.

Legacy UI.Text uses its own text/font helpers and lifecycle cleanup. Its original font is retained when it covers the translated characters. Otherwise, a native Font is created for the bundled file. On verified builds whose constructors do not initialize a dynamic face, the adapter populates only its newly created fallback's native byte vector through Unity's own allocator and calls the matched native font initialization helpers. The layout, allocator and helpers are selected by the full module fingerprint. Byte bounds, file length and the font header are checked before initialization; memory views are renewed after allocation. A probe glyph must succeed before the font is shared across observed labels or used to create an older TMP asset. A failed font attempt leaves the original font intact and reports the failure stage without text or credentials. Only the font reference changes; native sizes, styles and colors stay intact. Actual glyphs and layout require client verification. TMP processing also captures text paths that bypass the string property setter. Already-rendered translations do not create new bindings during mesh rebuilds, and world-space TMP labels release bindings when disabled or destroyed.

`bridge.js` provides a same-window string CustomEvent transport to the service worker. Page operations are restricted to public preferences, translation, bundled font chunks and sanitized status reports. Pages cannot select profiles, write settings, read credentials, export caches or invoke updates. All service requests originate in the extension, with configured API origin permission checks and omitted cookies. Storage access is restricted to trusted extension contexts.

The page runtime queues at most 512 waiting transport requests, with four active translations and six total active requests. Control requests have reserved capacity, and current dialogue is dispatched ahead of queued UI work. Provider concurrency remains two. Each transport deadline starts on dispatch, and completed bridge slots are released before further work is sent. Binding and preference generations remove obsolete queued requests before they reach the background. Pausing and disposal settle waiting work with the source; queue overflow and real provider failures still fall back without an unlimited retry loop.

Pending background translation sends same-window progress events once per second. These extend only the page bridge's idle deadline: queueing and sequential rich-text pieces do not masquerade as a provider timeout. Every provider fetch keeps its configured timeout, and a page translation has an additional fifteen-minute hard deadline. Progress contains no source text or credentials and stops on completion or failure. Model requests keep complete paragraphs and internal line breaks; only the free provider uses byte-limited chunks. Explicit native text preserves pipe separators while translating their surrounding words; unclassified ruby/control strings retain their original syntax.

Existing personal revisions for old newline pieces and free-provider byte chunks take precedence inside model paragraphs. The planner keeps those edited pieces intact and combines only unedited text around them; it does not discard them when changing request granularity.

Matched legacy text builds also capture the native mesh population path, catching backing-field writes and custom setters that bypass the standard property setter. TMP processing is hooked on all matched TMP builds. Kanji-only native labels can bind without dialogue context. A bounded output-to-source map prevents the extension's own translations from being retranslated when a component is reused; ambiguous outputs are not guessed. Oversized replacement strings release stale bindings. Capture diagnostics count observed entries and known skip reasons only; unknown renderers and unvisited scenes remain outside those counts, so they do not establish complete coverage.

`ProfileManager` separates shared providers/languages/switches from profile-specific rules and prompts. Each profile has a separate IndexedDB cache; keys include provider/body/prompt, target language and dialogue context. A bounded LRU avoids repeated IndexedDB access and SHA-256 work. Personal translations are kept separately and take priority.

Matched compiled-message scripts are collected during the application's existing preload traversal through a read-only argument getter. Command offsets link the collected lines to actual native dialogue progress. A fixed 0–20-line window warms one future sentence at a time; repeated frames cannot warm the entire chapter. Names are prepared alongside their lines. Prepared output reaches the native binding synchronously and bypasses a redundant display-time request, even if reference history has changed. Captured rows and characters are bounded, dynamic arguments are skipped, and scene or preference generations reject late results. Other script adapters only prefetch the beginning of a loaded plain script.

The text bridge records only current displayed dialogue; JSON and native script preload never populate history. A prefetched translation joins history only after its native display binding succeeds. Rule changes, profile changes, pause and cache edits advance preference revisions so old page work cannot replace new text. Already-consumed JSON cannot be restored without application integration or refresh. Native component bindings restore their original strings and discard callbacks after component disposal.

The updater checks product identity, ZIP paths, CRC and per-file SHA-256, backs up the original public code and rolls back failed writes. Browser configuration is retained by updating the existing installation directory. Hash checks establish package integrity, not an independent signing authority; use the project's releases.
