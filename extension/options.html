哪些界面文字可以翻译？
Label 和 RichText 文本组件可翻译；动态数值、聊天和输入框跳过。图片文字暂不覆盖。

文件格式与旧缓存说明
{
  "format": "unity-translations",
  "version": 1,
  "targetLanguage": "en",
  "translations": { "設定": "Settings" }

只修改 translations 中的译文值，保留标签与 targetLanguage。导入为合并；最多 10 MB、20000 条。旧缓存再次读取原文后可编辑。
