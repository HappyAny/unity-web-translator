# Security

Report a vulnerability through [GitHub private vulnerability reporting](https://github.com/HappyAny/unity-web-translator/security/advisories/new). Include the version, reproduction steps, and expected access boundary. Do not include real API keys or personal dialogue files.

The maintained release line is 0.1.x. Page scripts must never obtain provider credentials or settings authority. Only explicitly enabled origins may translate text. Imported data must be fully validated before writing.
