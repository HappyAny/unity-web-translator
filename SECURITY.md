# Security

Use [GitHub Issues](https://github.com/HappyAny/unity-web-translator/issues) to report a security concern with the affected version and a minimal, sanitized description. Issues are public: ask the maintainer for a private contact before sharing sensitive details. Do not publish API keys, personal dialogue files, or exploit details.

The maintained release line is 0.1.x. Page scripts must never obtain provider credentials or settings authority. Only explicitly enabled origins may translate text. Imported data must be fully validated before writing.
